# CODSOFT Cyber Security Internship

This repository contains the tasks and projects completed as part of my **Cyber Security Internship at CodSoft**. The internship focuses on practical learning, cybersecurity fundamentals, network analysis, secure coding, and security awareness.

## 📌 Internship Tasks

### Task 1 – Network Packet Analyzer
A Python-based application to capture and analyze network packets, including source IP, destination IP, protocol type, and packet information.

### Task 2 – Phishing Awareness Program
An educational program designed to raise awareness about phishing attacks, suspicious emails, fake login pages, fraudulent websites, and social engineering techniques.

### Task 3 – Secure Code Assessment
A security review of application source code to identify vulnerabilities, coding flaws, and suggest secure coding practices.

### Task 4 – Network Intrusion Detection System
A network security project using tools such as Snort or Suricata to detect suspicious traffic, generate alerts, and monitor potential threats.

### Task 5 – Secure File Sharing System
A secure file-sharing application with user authentication, file encryption, access control, and secure upload/download functionality.

## 🛠️ Technologies & Tools

- Python

- Snort / Suricata
- Networking Fundamentals
- Cybersecurity

## 🎯 Objective

To gain hands-on cybersecurity experience, improve technical skills, understand security threats, and apply cybersecurity concepts through practical projects.
